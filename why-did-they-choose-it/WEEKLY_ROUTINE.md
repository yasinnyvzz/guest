# لماذا اختاروه؟ — Weekly Cloud Routine

The weekly run follows these instructions. They mirror the series brief, so any run can work from this file alone.

## Every 7 days — one run = one article

1. **Read the queue:** `why-did-they-choose-it/QUEUE.md` (plus the published files, to avoid duplicates).
2. **Scan for news:** look for major new Arab procurement developments since the last run: contracts, DSCA notifications, deliveries, follow-on orders, cancellations, localisation deals.
3. **Update the queue:** if a new topic is stronger than a queued one, insert it with a full topic card and give the reason.
4. **Select ONE topic:** the highest priority that has enough sources.
5. **Research.** Primary sources first: ministries of defence, armed forces, official statements, procurement agencies, DSCA, manufacturers. Strong secondary sources: SIPRI, Janes, Defense News, Breaking Defense, Reuters, AP, FT, RUSI, CSIS, RAND, Naval News, The Defense Post, Shephard, and credible Arabic media.
6. **Verify.** Label every motive as one of: DOCUMENTED REASON / OFFICIAL JUSTIFICATION / MANUFACTURER CLAIM / REPORTED ANALYSIS / PLAUSIBLE BUT UNCONFIRMED.
7. **Write** in Arabic, using the fixed structure: H1 → direct answer → deal card → sections 1–13 → FAQ → sources.
8. **SEO:** title tag, meta description, slug, primary and secondary keywords, Article + FAQPage schema.
9. **Visuals:** 1 procurement timeline, 1 deal card, and 1 supplier map or comparison table when useful. Add alt text.
10. **Internal links** to published and queued series articles.
11. **Envanter Media:** add 0–1 link, only for a genuinely relevant Turkish system, and never as the only source.
12. **Save** as `why-did-they-choose-it/NN-<latin-slug>.md` with the status line `✅ READY TO PUBLISH`. Update the queue status and the publication log. Commit and push.
13. **Never write a second article in the same run.**

**SKIP rule:** if source quality is insufficient for the selected topic, try the next one. If no topic passes, record "SKIPPED — insufficient sources" in the publication log and publish nothing.

## Hard rules (checklist)

- [ ] Never invent political motives.
- [ ] Competitors are labelled CONFIRMED COMPETITOR / REPORTED ALTERNATIVE / SAME-CLASS THEORETICAL ALTERNATIVE. Never write "chose A over B" unless B was actually in the process.
- [ ] Price: separate unit, flyaway, package, contract value and DSCA ceiling. Never divide a package by quantity.
- [ ] SIPRI TIV ≠ USD.
- [ ] No "winner" conclusion. Present trade-offs, limitations and unknowns.
- [ ] Turkish systems: investigate them seriously and make an advantage prominent only if the evidence supports it. No advertising copy.
- [ ] Timeline stages appear only when a source supports them.
- [ ] Country first, requirement second, procurement third, product fourth. Evidence always.
