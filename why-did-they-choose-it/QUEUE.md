### تعديلات على قائمة المواضيع الأولية

- **الموضوع الأصلي 2** («لماذا استثمرت السعودية في قدرات صاروخية صينية…») **أُخرج من القائمة الرئيسية** لضعف المصادر الأولية. التعاون الصاروخي السعودي-الصيني موثّق أساساً عبر تسريبات استخباراتية وصور أقمار صناعية وتقارير CNN وغيرها، دون عقود أو بيانات رسمية، وهذا يجعل الالتزام بقاعدة «لا دوافع مخترعة» صعباً. **حلّ محله** الموضوع 8 (السعودية وF-35). يمكن العودة إليه إذا ظهرت وثائق رسمية.
- **الموضوع 7 الأصلي** (السعودية وتركيا) **رُفع إلى المرتبة 2** لأن ملف KAAN يشهد تطورات في 2026 ويمنح المقال توقيتاً إخبارياً قوياً.
- **الموضوع 3** (الجزائر) أُعيدت صياغته. بيانات SIPRI 2021–25 تُظهر تراجع واردات الجزائر 78%، مع روسيا 39% والصين 27% وألمانيا 18%. سؤال «لماذا التراجع؟» صار أقوى من سؤال «لماذا الاعتماد؟».

| **أفضل المصادر** | البيت الأبيض/الخارجية؛ DSCA إن صدر إخطار؛ Reuters؛ Armada International (فبراير 2026: «Saudi hedging its air requirements») |
| **الأهمية التركية** | متوسطة (KAAN كبديل مُتداول) |
| **Envanter Media** | ممكن، رابط واحد لـKAAN إن لم يُستخدم في #2 |
| **المفهوم البصري** | مصفوفة «ثلاثة مسارات جوية سعودية» |
| **الأولوية** | متوسطة. **ينتظر وثيقة رسمية.** إن لم تصدر، يُؤجّل أو يُدمج في #2 |

### #9 — لماذا تشتري دول الخليج من موردين متنافسين بدل الاعتماد على دولة واحدة؟

| الحقل | القيمة |
|---|---|
| **العنوان العربي** | لماذا تنوّع دول الخليج موردي السلاح؟ ما تقوله الأرقام وما لا تقوله |
| **الكلمة المفتاحية الرئيسية** | تنويع مصادر السلاح الخليج |
| **الدول** | السعودية، الإمارات، قطر، الكويت، عُمان، البحرين |
| **النظام** | متعدد (مقال محوري) |
| **سؤال الشراء** | هل التنويع حقيقي؟ SIPRI يُظهر أن الولايات المتحدة ما زالت المورد الأول للدول الأربع الكبرى (77% و48% و62% و42%) |
| **أفضل المصادر** | SIPRI؛ IISS Military Balance (إن توفر بشكل مشروع)؛ CSIS؛ RUSI |
| **الأهمية التركية** | متوسطة (الإمارات 12% من صادرات تركيا) |
| **Envanter Media** | لا في الغالب |
| **المفهوم البصري** | رسم بياني مكدّس لحصص الموردين لكل دولة (TIV) مع تنبيه TIV ≠ دولار |
| **الأولوية** | متوسطة. يُنشر بعد 3–4 مقالات تفصيلية ليكون صفحة محورية تربطها |

### #10 — الجزائر والسلاح الروسي: لماذا الاعتماد، ولماذا التراجع الآن؟

| الحقل | القيمة |
|---|---|
| **العنوان العربي** | لماذا اعتمدت الجزائر على السلاح الروسي؟ وماذا تعني أرقام تراجع وارداتها؟ |
| **الكلمة المفتاحية الرئيسية** | الجيش الجزائري السلاح الروسي |
| **الدولة** | الجزائر |
| **الأنظمة** | Su-30MKA، S-400 (تقارير)، Su-57 (تقارير 2025، **يُتحقق منها**)، MEKO A-200 (ألمانيا)، أنظمة صينية |
| **سؤال الشراء** | الإرث التاريخي؟ القيود الغربية؟ التمويل؟ ولماذا صعدت الصين وألمانيا؟ |
| **أفضل المصادر** | SIPRI (روسيا 39%، الصين 27%، ألمانيا 18%، تراجع 78%)؛ وزارة الدفاع الوطني الجزائرية (مجلة الجيش)؛ Rosoboronexport. **تحذير SIPRI: الجزائر «سرية» في وارداتها** |
| **الأهمية التركية** | منخفضة |
| **Envanter Media** | لا |
| **المفهوم البصري** | خط تطور حصص الموردين 2006–2025 |
| **الأولوية** | منخفضة-متوسطة. **يُتخطى إذا لم تتوفر مصادر كافية (SKIP rule)** |
